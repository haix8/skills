# Codex Skills

个人 Codex 技能仓库，用来集中存放可复用的自定义 skill。

## 已收录技能

- `douyin-ad-video-highlights`：把长视频、会议录制、课程回放、直播回放、产品演示或原始口播素材，整理成适合抖音 / TikTok 投流的短视频广告素材、切片方案、变体导出，以及可选的剪映 / CapCut 工程。
- `wechat-draft-publisher`：把已经写好的文章和封面图上传到微信公众号草稿箱。支持 Markdown 或已经排版好的微信 HTML。
- `voice-polish`（声剪）：口播视频自动剪辑。转写后由大模型校对错字、标出说错重来的句子，用静音检测剪掉气口和废句，烧录字幕，出片后用两个模型回转核对。macOS Apple 芯片实测，Windows 未实测。
