# 误读样本库（L2 / L3 纠错参考）

供交叉校验时比对用：遇到读起来不通顺的字，先在此表里找同形近音的字。

## ASR（L2）误识样本

**实测误识率不低，且视频越长错越多。**

- 38 秒教学视频：15 处以内
  `这三部 → 这三步`、`中忠心 → 中心`、`戴上 → 带上`
- 160 秒口播视频：15 处
  `刷豆淋 → 刷抖音`、`广味 → 广告位`、`取要的付费 → 渠道的服务费`、
  `加来的密头经济 → 但接下来的意图经济`、`现代商店 → 现在商家`

**反例：画面没有烧花字（纯口播 + 风景 / B-roll）时，L3 会返回噪声或空。**
此时 L2 ASR 是唯一来源，不要硬让 OCR 去"纠正" ASR。

## OCR（L3）误读样本

`parse_ocr.py` 的模糊合并已能处理多数残读，但**描边花字 + 艺术字**仍会整句认错：

| OCR 误读 | 实际字幕 |
|---|---|
| 代替人竺 / 飛替人門 / 從替人工 | 代替人工 |
| V型玻店 / X型坡口 混读 | V型坡口 |
| 天需二次打磨 | 无需二次打磨 |
| 亿醇坡口机 | 亿享坡口机 |
| 转加 / 翻转加尘 | 翻转加工 |

**纠错方法：用 `Read` 直接看关键帧**（开场 / 痛点段 / 产品亮相 / CTA 段 / 金句卡各一张）。
**时间轴用 OCR（密），关键字用肉眼（准）。**

## 抽帧里混入的噪声

- `DANGER` / `KEEP TO CLEAN` 是机器警示标签；
- 卷尺刻度会被读成 `3456789201`。

这类要直接剔除，不要进文案。
